# Onboarding wizard brand icons

Vendored third-party brand marks shown as option icons on the onboarding
wizard's CRM and lead-source questions. Vendored rather than hotlinked so the
product's first screen never depends on a third-party CDN.

Sources:

- `hubspot.svg`, `salesforce.svg`, `zoho.svg`, `pipedrive.svg`, `facebook.svg`,
  `google-ads.svg` — the [gilbarbara/logos](https://github.com/gilbarbara/logos)
  catalog (MIT-licensed repository).
- `odoo.svg`, `activecampaign.svg` — worldvectorlogo.com.
- `clientify.png`, `bitrix24.png`, `escala.png` — the products' own published
  favicons.
- `ghl.png` — the official HighLevel app icon.

All trademarks and logos are the property of their respective owners and are
used nominatively, solely to identify the third-party product an option refers
to. No affiliation or endorsement is implied. If you are a rights holder and
want a mark removed, open an issue.
