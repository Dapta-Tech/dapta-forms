The MCP page can show two ways in. When the web runs with `MCP_OAUTH_PROVIDER` set like the API's and `MCP_PUBLIC_URL` set to the API's value (the audience of every token), a chat path comes first: copy the MCP URL, add it as a connector in Claude.ai or ChatGPT (the steps of both side by side) and sign in, with no key. The API key guide follows as the path for terminal agents (Claude Code, Codex, Cursor), and the note that chat apps cannot connect yet goes away. Without either value, the page stays as it was. New catalog keys in English and Spanish: `admin.developers.subtitleOauth`, `admin.developers.guide.chat` and `admin.developers.guide.terminal`.
